CleanBox AI - Project Details
Technology Stack
PHP OOP MySQL Google OAuth 2.0 Gmail API Chart.js Bootstrap 5 AOS
Live Demo Source Code
Project Overview

CleanBox AI is a sophisticated email management tool designed to help users reclaim their inbox and digital storage. Built with PHP and integrated with the Google Gmail API, it provides an intelligent dashboard to scan, categorize, and bulk-delete unnecessary promotional content and expired verification codes.

Key Features
  • AI-Powered Scanning: Accurate identification of unnecessary emails using keyword analysis.
  • Bulk Cleanup: Safely delete hundreds of emails simultaneously.
  • Real-Time Analytics: Visual reports (Chart.js) showing storage space recovered.
  • Smart OTP Cleanup: Advanced logic to find and remove expired verification codes.
  • Secure Login: Integrated with official Google OAuth system for privacy.
  • SPA Experience: Modern, seamless UI with persistent sidebar and navbar.

SkyCast Weather Dashboard - Details
Technology Stack
JavaScript (ES6+) Open-Meteo API Chart.js Bootstrap 5 Glassmorphism UI Web Speech API
Live Demo Source Code
Project Overview

SkyCast is a high-fidelity, production-grade weather dashboard designed to provide a premium user experience. It focuses on visual excellence and interactive data, featuring a sleek Glassmorphism UI and dynamic backgrounds that change in real-time based on weather conditions.

Key Features
  • Glassmorphism UI: Modern design using blur filters and semi-transparent overlays.
  • Interactive Data: Custom temperature trend graphs using Chart.js with 24-hour forecasts.
  • Dynamic Backgrounds: Logic system that switches UI themes based on weather states (Sunny, Rainy, etc.).
  • Voice Search: Integrated Web Speech API for hands-free weather updates.
  • Intelligent Search: Real-time city search with smart autocomplete powered by Geocoding API.
  • Theme & Unit Toggle: Light/Dark modes and Celsius/Fahrenheit preferences saved locally.

CineWave | Movie Search - Details
Technology Stack
HTML5 / CSS3 JavaScript ES6 Bootstrap 5 OMDB API LocalStorage Font Awesome

Project Overview

CineWave is a premium movie search application that bridges the gap between clean UI design and functional API integration. Inspired by the Netflix user experience, it allows users to explore a vast database of films, view detailed insights, and manage a personal watchlist—all within a seamless, responsive dark-themed environment.

Key Features
  • Netflix Aesthetics: Dark mode, glassmorphism, and smooth hover animations for a premium feel.
  • Real-time Search: Instant search suggestions and results using the OMDB API.
  • Interactive Watchlist: Add/remove movies from your list with persistence via LocalStorage.
  • Detailed Overlays: High-fidelity modals showing ratings, cast, plot, and runtime.
  • Responsive Grid: Perfectly optimized for mobile and desktop viewing.
